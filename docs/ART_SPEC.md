# 아트 규격 — AI 생성 후 보정

## 규격

| 항목 | 값 |
|---|---|
| 게임 해상도 | 1920 × 1080 |
| 배경 | 1920 × 1080, PNG 또는 품질 높은 JPG |
| 캐릭터 스프라이트 | 세로 1200px 이상, **투명 배경 PNG**, 무릎 위 |
| 표정 차분 | 캐릭터당 최소 6종 |
| CG (이벤트 일러) | 1920 × 1080 |
| 스팀 캡슐 | 616×353 / 231×87 / 460×215 / 1920×620 |

표정 6종: 기본 / 놀람 / 공포 / 분노 / 슬픔 / 무표정

## 일관성 유지 — 여기서 게임 퀄리티가 갈린다

AI 아트의 유일하고 최대인 약점이 캐릭터 동일성이다. 순서를 지켜라.

### 1. 캐릭터 시트를 먼저 고정한다
정면 / 3-4 측면 / 전신 한 장씩 만들고, **마음에 들 때까지 여기서만 반복한다.**
이게 확정되기 전에 표정 뽑기 시작하면 전부 다시 해야 한다.

### 2. 프롬프트 블록을 파일로 관리한다
`art_source/prompts/지혜.txt` 같은 식으로. 캐릭터마다 고정 블록 + 가변 블록으로 나눈다.

```
[고정] 20대 초반 여성, 어깨 길이 검은 단발, 앞머리 없음,
       가는 은테 안경, 짙은 회녹색 카디건, 흰 셔츠 깃,
       왼쪽 눈썹에 작은 흉터
[가변] 표정: {놀람}
```

고정 블록은 **한 글자도 바꾸지 않는다.**

### 3. 시드 고정 + i2i
캐릭터 시트를 img2img 소스로 넣고 표정만 바꾼다. 처음부터 다시 생성하지 않는다.

### 4. 배경은 사진 기반이 안정적이다
직접 찍거나 무료 사진 → img2img → 후보정. 텍스트-투-이미지보다 공간 일관성이 훨씬 낫다.

### 5. 색보정 LUT 한 개로 전체를 통과시킨다
**가장 효과가 큰 단일 작업.** 배경·스프라이트·CG 전부에 같은 색보정을 걸면
서로 다른 소스에서 나온 그림도 한 세계처럼 보인다.

호러/미스터리 권장: 채도 -25%, 하이라이트에 청록, 그림자에 약간의 갈색, 대비 +10%

## 반드시 손봐야 하는 것

AI가 매번 틀리는 부분. 납품 전 체크리스트.

- [ ] 손가락 개수와 관절
- [ ] 좌우 눈 크기·시선 방향
- [ ] 안경테 좌우 대칭
- [ ] 옷의 단추/주머니/무늬가 좌우로 이어지는가
- [ ] 액세서리가 컷마다 유지되는가
- [ ] 표정 차분 간 얼굴 크기·위치가 정확히 겹치는가 ← 안 맞으면 표정 바뀔 때 얼굴이 튄다
- [ ] 배경에 글자처럼 생긴 뭉개진 형태가 없는가
- [ ] 투명 배경 가장자리에 흰 테두리 없는가

표정 차분은 **레이어를 겹쳐서 위치가 1픽셀도 안 어긋나는지** 확인한다.

## Steam AI 공개 대응

플레이어가 보고 듣는 AI 생성물은 신고 의무 대상이다. 이 프로젝트는 확실히 해당된다.

- 신고할 것: 배경, 스프라이트, CG, 스토어 캡슐 아트, AI로 만든 음성·음악, AI 번역
- 신고 안 해도 되는 것: 코드 작성에 쓴 Claude Code / Codex (개발 효율 도구는 면제)

스토어 페이지에 어떻게 썼는지 **구체적으로** 쓰는 편이 반응이 낫다.
"AI로 빨리 만들었습니다"가 아니라 "배경은 직접 촬영한 사진을 기반으로 생성 후 전량 수동 보정했습니다" 쪽.

## 사운드

그림보다 싸고 효과가 크다.

- 무료 BGM: DOVA-SYNDROME, 甘茶の音楽工房 (상업 이용 가능, 라이선스 조건 각각 확인)
- 무료 효과음: freesound.org (CC0 필터), zapsplat
- 환경음(빗소리, 형광등 웅웅거림, 배관음)은 직접 녹음해도 된다. 폰으로 충분하다.

**라이선스 문서를 다운로드할 때마다 같이 저장해라.** 출시 직전에 찾으면 지옥이다.
