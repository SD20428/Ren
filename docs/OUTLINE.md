# 시나리오 구조 — 3시간 미스터리/호러

## 분량 계산

한국어 VN 체감 읽기 속도는 분당 400~500자 수준(연출·대기 포함).

- 3시간 = 180분
- 순수 텍스트 **6만 ~ 8만 자**
- 원고지 400자 기준 **150~200매**

중편 소설 한 권 분량이다. 이게 이 프로젝트의 진짜 작업량이고, 엔진이나 코드가 아니라 여기서 끝난다.

권장 페이스: 하루 1,500자 → 약 7주에 초고. 리라이팅에 그만큼 또 든다.

## 챕터 배분

| 챕터 | 분량 | 역할 |
|---|---|---|
| 00 프롤로그 | 5분 | 훅. 설명 없이 상황만 던진다 |
| 01 | 20분 | 일상과 공간을 익히게 한다. 이상 징후 1개 심기 |
| 02 | 25분 | 첫 사건. 되돌아갈 수 없어진다 |
| 03 | 30분 | 조사 / 단서 수집. **첫 분기** |
| 04 | 25분 | 반전 1. 지금까지 믿던 것 하나가 뒤집힌다 |
| 05 | 30분 | 추격·압박. 호러 밀도 최대 |
| 06 | 25분 | 진실. 심어둔 복선 회수 |
| 07 | 20분 | 최종 선택 → 엔딩 분기 |

## 엔딩 4종

| 라벨 | 조건 | 성격 |
|---|---|---|
| `ending_ash` | 정신력 0 또는 지하실만 열고 사진 못 봄 | 배드 |
| `ending_default` | 위 조건 미달 | 노멀. 아무것도 모른 채 끝남 |
| `ending_true` | 단서 3개 + 사실대로 말함 + 신뢰 2 이상 | 트루 |
| (추가 예정) | | 숨겨진 엔딩 |

판정 로직은 `game/flags.rpy` 의 `decide_ending()` 한 곳에만 있다. 분산시키지 말 것.

## 미스터리 규칙 — 어기면 리뷰에서 욕먹는다

1. **모든 단서는 회수 전에 최소 2회 노출된다.** 마지막에 새 정보로 해결하면 사기다.
2. **범인/진상은 3장 이전에 화면에 등장해 있어야 한다.**
3. **플레이어가 아는 것 = 주인공이 아는 것.** 주인공만 아는 정보로 숨기지 않는다.
4. 선택지는 **결과를 예상할 수 있게** 만든다. 랜덤 즉사 금지.
5. 배드엔딩 직전에 되돌아갈 지점을 준다.

## 호러 규칙

1. 점프 스케어는 **챕터당 최대 1회.**
2. 보이지 않는 것이 보이는 것보다 무섭다. 괴물 전신샷은 마지막 한 번만.
3. 무서운 장면 앞에 반드시 조용한 구간을 둔다. 대비가 공포를 만든다.
4. 소리가 절반이다. BGM 끄고 환경음만 남기는 구간을 적극 쓴다.
5. 안전지대를 하나 만들어 두고, 후반에 그곳을 침범한다.

## 작성 순서 권장

1. 엔딩 4개를 **먼저** 확정한다
2. 각 엔딩에 필요한 단서와 플래그를 역산한다
3. 챕터 요약을 한 줄씩 쓴다 (8줄)
4. 그다음에 대사를 쓴다

거꾸로 하면 3장쯤에서 길을 잃는다.
