# 시나리오 구조 — 3시간 미스터리/호러

## 분량 계산

한국어 VN 체감 읽기 속도는 분당 400~500자 수준(연출·대기 포함).

- 3시간 = 180분
- 순수 텍스트 **6만 ~ 8만 자**
- 원고지 400자 기준 **150~200매**

중편 소설 한 권 분량이다. 이게 이 프로젝트의 진짜 작업량이고, 엔진이나 코드가 아니라 여기서 끝난다.

권장 페이스: 하루 1,500자 → 약 7주에 초고. 리라이팅에 그만큼 또 든다.

## 엔딩 4종

판정 **순서가 우선순위**다. 위에서 걸리면 아래는 안 본다.

| 순 | 라벨 | 조건 | 성격 |
|---|---|---|---|
| 1 | `ending_ash` | `sanity <= 0` | 배드. 강제 |
| 2 | `ending_hidden` | 단서 3개 + `f_told_truth` + 신뢰 3 + `sanity >= 4` + `f_opened_door` | 히든 |
| 3 | `ending_true` | 단서 3개 + `f_told_truth` + 신뢰 2 이상 | 트루 |
| 4 | `ending_ash` | `f_opened_door and not f_saw_photo` | 배드 |
| 5 | `ending_default` | 위 전부 미달 | 노멀. 아무것도 모른 채 끝남 |

히든은 트루의 상위 집합이다. 트루 조건을 전부 만족한 위에 흠집이 없어야 한다.

`sanity` 주의: 프롤로그의 `drain_sanity(1)` 때문에 5 는 도달 불가하다. **4 가 만점**이다.
그래서 히든 조건이 `>= 4` 다. 프롤로그의 소모를 지우거나 옮기면 이 숫자도 같이 고쳐야 한다.

신뢰 주의: 히든은 `trust_jihye 3`(최대치)을 요구한다. +1 기회가 최소 3번 있어야 도달 가능하다.
현재 배치는 03 / 04 / 06 세 곳. 여기서 하나라도 빼면 히든이 죽는다.

판정 로직은 `game/flags.rpy` 의 `decide_ending()` 한 곳에만 있다. 분산시키지 말 것.

## 단서 역산 — 노출 2회 → 획득 → 회수

미스터리 규칙 1(회수 전 최소 2회 노출)을 표로 강제한다. **노출 ≠ 획득.**
노출은 "화면에 스치기"고, 획득은 `add_clue()` 호출이다.

| 단서 ID | 노출 1 | 노출 2 | 획득 | 회수 |
|---|---|---|---|---|
| `clue_photo` | 01 (서랍이 반쯤 열려 있다) | 04 (다시 꺼내 본다) | 01 `ch01_choice_drawer` | 06 |
| `clue_burnt_letter` | 02 | 03 | 03 `ch03_choice_search` A | 06 |
| `clue_key` | 02 | 03 | 03 `ch03_choice_search` B / 05 보충 | 06 |

03 의 분기는 단서 하나만 준다. **놓친 쪽은 05 에서 반드시 주워갈 수 있어야 한다.**
안 그러면 단서 3개가 모이지 않아 트루·히든이 통째로 막힌다. 이게 이 구조의 유일한 급소다.

## 플래그 설정 지점

| 플래그 | 설정 위치 | 쓰이는 곳 |
|---|---|---|
| `f_saw_photo` | 01 `ch01_choice_drawer` | `ending_ash` 조건 |
| `f_opened_door` | 05 | `ending_ash` / `ending_hidden` 조건 |
| `f_told_truth` | 07 `ch07_choice_truth` | `ending_true` / `ending_hidden` 조건 |
| `trust_jihye` | 01(-1) / 03(+1) / 04(+1) / 06(+1) / 07(-1) | `ending_true` / `ending_hidden` 조건 |
| `sanity` | 00(-1, 무조건) / 02·05 는 **조건부만** | `ending_ash` / `ending_hidden` 조건 |
| `jump_scare_used` | `begin_chapter()` 가 챕터마다 초기화 | `use_jump_scare()` |

`sanity` 규칙: **무조건 소모는 프롤로그 1회뿐이다.** 02·05 의 소모는 플레이어가 피할 수 있는
선택·행동에만 걸어라. 무조건 깎는 지점을 하나라도 더 만들면 히든(`>= 4`)이 도달 불가가 된다.
소모 지점을 늘리고 싶으면 히든 기준을 같이 내려라 — 둘 중 하나는 반드시 따라와야 한다.

## 정신력 예산 — 엔딩 5갈래가 다 살아있는 조건

`sanity` 는 5 로 시작하고 프롤로그에서 무조건 1 깎인다. 남은 예산이 두 엔딩을 동시에 결정한다.

- `ending_ash`(정신력 0) 도달에 필요: **회피 가능한 -1 지점 4개 이상**
- `ending_hidden`(정신력 4) 도달에 필요: **그 지점을 전부 피할 수 있어야 함**

즉 소모 지점은 "많이, 그리고 전부 회피 가능하게" 깔아야 한다. 권장 배치는 02·03·04·05·06 에
회피 가능한 -1 을 하나씩(총 5). 무조건 소모를 하나라도 추가하면 히든이 즉시 죽는다.

전 조합을 열거해서 확인한 결과, 위 배치에서 5갈래(`ash(sanity)` / `hidden` / `true` /
`ash(door)` / `default`)가 모두 도달 가능하다. 단 **히든은 경로가 정확히 1개**다 —
서랍 열고, 신뢰 3 전부 얻고, 소모 전부 회피하고, 사실대로 말하고, 지하실까지 들어간 주행.
사실상 2회차용이다. 여유가 0이므로 밸런스를 건드릴 때마다 이 표를 다시 계산해라.

## 미스터리 규칙 — 어기면 리뷰에서 욕먹는다

1. **모든 단서는 회수 전에 최소 2회 노출된다.** 마지막에 새 정보로 해결하면 사기다.
2. **범인/진상은 3장 이전에 화면에 등장해 있어야 한다.**
3. **플레이어가 아는 것 = 주인공이 아는 것.** 주인공만 아는 정보로 숨기지 않는다.
4. 선택지는 **결과를 예상할 수 있게** 만든다. 랜덤 즉사 금지.
5. 배드엔딩 직전에 되돌아갈 지점을 준다.

## 호러 규칙

1. 점프 스케어는 **챕터당 최대 1회.**
2. 보이지 않는 것이 보이는 것보다 무섭다. 괴물 전신샷은 마지막 한 번만.
3. 무서운 장면 앞에 반드시 조용한 구간을 둔다. 대비가 공포를 만든다.
4. 소리가 절반이다. BGM 끄고 환경음만 남기는 구간을 적극 쓴다.
5. 안전지대를 하나 만들어 두고, 후반에 그곳을 침범한다.

## 작성 순서 권장

1. 엔딩 4개를 **먼저** 확정한다
2. 각 엔딩에 필요한 단서와 플래그를 역산한다
3. 챕터 요약을 한 줄씩 쓴다 (8줄)
4. 그다음에 대사를 쓴다

거꾸로 하면 3장쯤에서 길을 잃는다.
