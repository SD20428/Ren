# 스팀 출시 체크리스트

## 0. 시작 전 (게임 만들기 전에 확인)

- [ ] Steamworks 계정 명의 확보 — 세금서류(W-8BEN) + 은행계좌 + 신분확인 필요. 미성년자면 보호자 명의
- [ ] $100 결제 수단
- [ ] 게임 제목이 스팀에 이미 있는지 검색

## 1. 개발 중

- [ ] git 커밋 습관화
- [ ] 에셋 라이선스 문서 전부 보관 (`docs/licenses/`)
- [ ] 데모용으로 잘라낼 구간 미리 정하기 (프롤로그 ~ 1장 권장)
- [ ] 세이브/로드 실제로 테스트 — 3장 세이브를 6장 빌드에서 열어본다
- [ ] 해상도 변경, 창모드 전환 테스트

## 2. 스토어 페이지 (출시 최소 6주 전)

- [ ] Steam Direct $100 결제 — **결제 후 30일 강제 대기**
- [ ] Coming Soon 페이지 공개 — **출시 최소 2주 전**
- [ ] 캡슐 아트 4종
- [ ] 트레일러 (첫 5초가 전부. 로고부터 띄우지 말 것)
- [ ] 스크린샷 5장 이상 — 대사창이 보이는 실제 게임 화면으로
- [ ] 짧은 설명 (한 문장으로 뭘 하는 게임인지)
- [ ] 태그: Visual Novel, Horror, Mystery, Psychological Horror, Story Rich, Singleplayer
- [ ] **AI 생성 콘텐츠 신고란 작성**
- [ ] 콘텐츠 등급 설문

## 3. 위시리스트 쌓기 (여기가 실제 승부처)

- [ ] Coming Soon 공개 후 최소 2~3개월 확보
- [ ] Steam Next Fest 참가 → 데모 필요
- [ ] 개발 로그 꾸준히 (X, 레딧 r/visualnovels, 디시/아카라이브)
- [ ] 스트리머·리뷰어에게 키 배포

기준선: Next Fest 진입 시 위시리스트 2,000 미만이면 부스트가 거의 없다.

## 4. 출시 직전

- [ ] 다른 PC에서 빌드 실행 테스트 (개발 PC에만 있는 폰트/DLL 함정)
- [ ] 백신 오탐 확인
- [ ] 스팀 대형 세일 기간 피하기
- [ ] 가격 결정 — 3시간 VN이면 대략 $7~10 구간

## 5. 현실 인식

2025년 스팀에 약 19,000개가 나왔고 연 10만 달러를 넘긴 건 5,863개다.
나머지 13,000개는 개발비도 못 건졌다. VN은 그중에서도 상위권 장르가 아니다.

첫 작품의 목표는 매출이 아니라 **완성하고 출시하는 것.**
출시 이력, 스팀 리뷰, 실제 유저 피드백이 다음 작품의 자산이 된다.

## 타임라인 최소치

```
게임 완성 ──▶ $100 결제 ──30일 대기──▶ 출시 가능
                  └── Coming Soon 공개 ──2주 이상──┘
```

최소 6주. 위시리스트까지 감안하면 **3~4개월 잡아라.**
